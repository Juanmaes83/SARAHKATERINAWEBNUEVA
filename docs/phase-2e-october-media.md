## Advisory scenes

Both are staged editorial scenes. The other people are not presented as real
clients; no case, testimonial or outcome is implied, and the word "CLIENTE"
from the file names is not carried into any public text. Alt text opens with
"An editorial advisory scene" (enforced by `tests/october-media.test.ts`).
Generation method and model release are not recorded — confirm before
production.

## Derivatives and grade

- Web derivatives in `public/media/`, graded copies in `public/media/graded/`
  via `node scripts/grade-media.mjs` (grade `sk-editorial-v1`, no CSS filters).
- Door and asset images are resized to 1280px wide (1200px for
  `property-in-mind`): their largest rendering is about 384 CSS px, and this
  keeps each graded file under the 250 KB budget. The advisory scenes keep
  their native size.
- The 14 existing graded files were regenerated byte-identical.

## Focal points

- New optional `ApprovedMedia.compactFocal`, used by `TerritoryVisual` only
  when a slot renders with `crop="compact"` (the default). The doors become a
  narrow portrait column beside the text from 1280px; both door images have the
  person at the left edge, so `compactFocal` keeps her in frame (`8% 50%`,
  `12% 50%`). Other slots are unaffected.
- `PENDING_MEDIA_SLOTS` no longer lists the Investment decision doors.
